# KAI 記帳 PWA

這是可以在手機瀏覽器使用的記帳 PWA 原型。

## 目前功能

- 聊天式新增記帳，例如輸入 `午餐 120`。
- 自動推測簡單分類。
- 本月支出、今日支出自動加總。
- 紀錄頁可切換月份。
- 欠款頁可新增朋友、項目、金額。
- 可刪除記帳紀錄或結清欠款。
- 資料存在手機瀏覽器本機。
- 支援 PWA manifest 與離線快取。
